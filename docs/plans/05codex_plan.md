# CCG semantic parser experiments · implementation plan 05

**First implementation task.** Spend two engineering days on *Every researcher reviewed a paper*. The first investment decision comes later. Before funding runtime adapters, establish whether the grammar can interpret **new combinations of familiar constructions** at useful coverage, accuracy, and CPU cost. A high score on familiar sentence patterns alone cannot answer that question.

This plan revises the experimental protocol in response to Claude’s second review. The milestone IDs, parser contracts, baseline implementations, and engineering budgets refer to the 03 plan. The tables here govern sampling, scoring, audit effort, and decisions. Their numbers are proposals to approve at M01, before bulk annotation. [03 implementation plan](03codex_plan.md) · [04 review](04_review_claude.md)

## 1. Spike and M01 sign-off order

1. **Build the scope spike.** Tokenize the sentence, map *reviewed* to its lemma and tense feature, and carry both scope recipes through the packed verb phrase to one root. Emit two witnessed, normalized readings. In a world where two researchers each reviewed a different paper and neither reviewed the other’s, only the researcher-wide reading is true. Reverse lexical insertion order and require identical meanings and tie order. Save the smallest failing fixture if either check fails.
2. **Freeze the sampling design.** Assign generator custody, define combination families, fix the ambiguity mixture below, and test the access boundary. Pin the ontology, scope policy, two-axis result schema, set serialization, and world-bank recipe.
3. **Run a 100-input pilot.** Use training-only examples, including 20 with two readings. Check teacher costs and conflicts, tokenizer round trips, reader disagreement, and the number of distinct outputs requiring judgment. Record what can be measured with the systems available at this stage.
4. **Sign the protocol.** Two readers resolve all disagreements on 12 worked fixtures. Record the approved thresholds, reader and compute budgets, frozen manifests, and permitted tuning data. Start bulk annotation only after this sign-off. A change to a threshold, mixture, or scoring rule after examining results gets a new protocol version and a new confirmatory sample.

## 2. Independent generation and registered populations

**D, the repository maintainer, owns the generator and evaluator in a private environment.** D can assign generation to a data contributor who has no grammar or baseline-authoring role. A owns grammar and ontology. B validates the Python reference against an independently implemented tiny oracle. C owns teacher annotation, model training, and development reports. A and the model builders receive the same training texts and teacher targets, public task specification, and ordinary development diagnostics. Generator source, template lists, per-input generation recipes, reserved combinations, and intended meanings stay with D. Before generating data, test from each author environment that it cannot read a private sentinel. Record the responsible people or agent configurations and access results.

For every generated input, D records the intended meaning, the **full set of licensed sentence-only readings**, their construction signature, group IDs, and generator revision. The selection of one meaning to generate an utterance does not settle the utterance’s ambiguity. Compare the teacher’s reading set with the private set on every input. Log omissions, extra readings, ontology disagreements, and invalid responses. Have a reader resolve substantive conflicts blind to system identity. Version corrections and publish unresolved counts. Preserve the original teacher response for the fidelity metric. The private targets never become additional training labels.

## 3. Same answer contract for every system

The symbolic parser, neural baseline, frontier teacher, and ACE/ERG mapping each return a singleton, a set of distinct readings, or abstention. Preserve the construction and decision axes from 03 for the parser. Record baseline-specific failures explicitly, including malformed model output and unmapped ERG predicates. Train the neural baseline to serialize the complete reading set as one target. Give it the same context, two-reading capacity, and evaluation policy as the grammar. The teacher prompt requests the **complete licensed set** and permits an optional preference in a separate field. Preference affects only a secondary ranking score. Missing or uncertain teacher labels retain their own status.

Sort and deduplicate meanings under the same exact normalizer. Two derivations of *Alice reviewed Bob* may therefore support one accepted answer. Conversely, a system returning only one of two licensed scope readings receives an incomplete-set error, even if it chose the teacher’s preferred reading.

| Mutually exclusive evaluation outcome | Rule |
| --- | --- |
| Correct single answer | Input has one licensed reading and the system accepts it. |
| Correct ambiguous answer | Input has two licensed readings and the system returns exactly that set as ambiguous. |
| Abstained | System declines to answer, including the initial policy for truncated searches. Preserve the reason and construction status. |
| Wrong or invalid | System attempts an answer with a wrong role, missing or extra reading, wrong decision, or invalid serialization. Preserve the diagnostic. |

**Co-primary results** are set-aware correct yield on the full controlled split and on its transfer stratum, for both symbolic and neural systems. Each numerator counts correct single and correct ambiguous answers. Each denominator includes every assigned input. Score against D’s frozen licensed sets, disclose unresolved labels, and give lower and upper yield bounds for rows whose correctness cannot be determined. Use the conservative bound for a pass. Report the four outcome counts, singleton accepted coverage on all inputs and on single-reading inputs, correct singleton yield, human-adjudicated accuracy among accepted outputs, and exact teacher agreement separately. A wrong accepted singleton still enters the accepted-accuracy denominator. Correct ambiguity earns set-aware credit and contributes zero singleton coverage.

**Neural serialization gate.** Pin the FLAN-T5-base checkpoint, tokenizer revision, special-token rules, and decoder settings. D tests the 100 canonical pilot target sets in private and C tests every validated training target before training. Both checks require byte-identical canonical text after encode/decode, an identical parsed AST/set, and zero unknown target tokens. Exercise braces, angle brackets, binders, and the set delimiter in fixtures even if absent in the pilot. If any check fails, adopt a reversible token-safe serialization or version an extended tokenizer and model vocabulary. Rerun the entire check and preserve the failing example. Include tokenization and decoding in CPU timing.

## 4. Finite-model scoring, including control

B freezes **256 worlds** for a bounded behavioral check, using fixed entity and event IDs across worlds. Allocate four entities (two researchers and two papers) and three event slots. Use the two researcher IDs for the named control participants.

- Enumerate 64 worlds exhaustively over six designated bits. For each of two review events independently vary whether it is a review, whether its corresponding researcher is its agent, and whether its corresponding paper is its theme. Fix the remaining relations for this sub-bank.
- Supply 16 hand-checked countermodels for argument reversal, shared versus separate papers, polarity, controller identity, non-veridical content, and attachment. Include worlds where nobody leaves, only Alice leaves, and only Bob leaves.
- Generate 176 further distinct worlds by sampling legal typed predicate and role assignments. Seed the generator with `20261119`, pin its algorithm and schema, reject duplicate world encodings, and publish the final bank digest and bit ordering. Freeze it before scoring any candidate.

For a closed formula compare its truth vector across the bank. For `Box(φ)`, keep the outer variable assignment fixed and compute the payload vector across the same worlds. The matrix event’s content relation takes that vector as a value. Freeze independent content fixtures for the named and quantified controllers, including a promise in a world where nobody actually leaves. Compare matrix and payload signatures under the same assignments. A promise and a persuasion with swapped embedded agents must disagree on a separating fixture. Evaluate payloads as data so an ordinary unboxed query in an otherwise empty store retrieves zero asserted leaving events from either a promise or a negated clause.

Compare sets of behavioral signatures as a diagnostic alongside exact normalized set agreement and human judgment. A differing world or assignment is a replayable counterexample. Agreement establishes behavior on this finite bank. Publish the eligible count and named gaps for any constructor beyond the evaluator’s contract.

## 5. Budget adjudication by distinct outputs

Start with the 03 sampling targets of 200 controlled development inputs, 100 natural development inputs, and all 500 locked controlled inputs. Stratify by ambiguity and transfer, select before inspecting predictions, and keep transfer judgments sealed until candidate freeze. Plan a second independent reading on 20% of audited judgments and resolve disagreements. Budget up to four grammar growth checkpoints, the frozen grammar and neural systems, teacher, and the ERG mapping wherever available. The native parser can share a judgment when its canonical response agrees with the reference.

Use a common blind audit panel for all systems at each eligible checkpoint. One feasible allocation for the 200 controlled development cases is 160 ordinary and 40 transfer, with 20% ambiguous within each group. Rescore only changed ordinary outputs during growth. Open the transfer panel once.

During the 100-input pilot, count distinct **(input, context, decision, normalized reading set)** judgments across available systems. Time first reads, second reads, and reconciliations. Count changed outputs requiring a new judgment between versions. Reuse an earlier blind rating only for an identical key and rubric version. For a baseline or checkpoint that does not yet exist, budget one additional distinct judgment per sampled input per run as an upper bound. Repeat the estimate when the first paired model and grammar outputs become available. The 80 hours in 03 describes one output per input and one pass through the samples.

D computes reader-hours from distinct judgments × measured minutes per read, plus second reads, reconciliation, and generator/teacher conflict review. Record a measured estimate and an upper budget before bulk annotation. If hours are fixed, reduce sampled **inputs across all systems together**, stratify and record inclusion probabilities, and use weighted estimates for unequal sampling. Preserve complete automatic scoring for every input. Freeze any audit reduction before seeing candidate scores. Report the release gate as inconclusive if the accepted audit is too small to support its bound.

## 6. Gates and stop rules

**Decision 1 · seed correctness.** Proceed to M13 only when the semantic contrasts all pass, both scope readings survive, and the exact reference agrees with the independent exhaustive oracle on every mandatory tiny fixture. M02–M08 retain the 03 checks for binding, normalization, type checking, complete chart keys, idempotent edges, witnessed extraction, and deterministic ranking. Recover the companion checker or document replacement coverage of the seven Appendix B families.

**M13 · growth and freeze.** Use at most four weekly rounds. Estimate progress on the ordinary development sample. Freeze the best contrast-passing candidate after two successive gains below two percentage points in audited correct singleton yield, at the four-round cap, or earlier when ordinary development meets its preregistered targets. Break ties by native p95 latency. Freeze the neural checkpoint and decoding policy on ordinary data on the same schedule. Keep the calibration split for the later locked evaluation. For an early freeze, require the two coverage targets on ordinary development alone (≥480/800 overall and ≥480/640 single-reading cases), the 95% audited accuracy target, and native parity and resource checks.

**Decision 2 · fund adapters only if all of these hold.**

| Check on frozen development candidates | Proposed rule |
| --- | --- |
| Single-answer coverage | At least 600/1,000 complete, accepted symbolic answers overall (60%) and at least 600/800 on single-reading inputs (75%). With this mixture a perfectly ambiguity-aware system can accept at most 800 single answers. Report both fractions so accepting one reading on ambiguous inputs cannot rescue a shortfall on singles. |
| Semantic quality | At least 100 audited controlled development cases receive accepted symbolic outputs, with ≥95% adjudicated accepted accuracy. Report results for both co-primary populations and both ambiguity strata, including correct-set counts. |
| Native feasibility | Rust matches the Python reference on the registered suite and meets the 03 serving budget on one pinned CPU core at batch one, with resident p95 ≤100 ms, peak process-group memory ≤1 GiB, and a 1 s request deadline. |
| Compositional transfer versus neural | On the same 200 transfer inputs compute **neural minus symbolic set-aware correct yield**. Ten percentage points correspond to 20 net correct answers. Use paired family-cluster resampling within the registered mixture for one-sided 95% limits. Proceed only if the upper limit is below +10 points. If the lower limit is at least +10 points, stop adapter investment even if the native parser is faster. An interval spanning the margin leaves the investment decision inconclusive. Publish the gap, interval, family count, and paired outcomes. |

Also stop adapter investment if the measured neural baseline dominates the symbolic system in adjudicated quality, coverage, latency, and lifetime cost at the registered load. A failed or inconclusive adapter gate still yields a primary study. Keep the 03 neural learning curves, native Rust port, existing symbolic mapping, and teacher baseline in that report.

**M14/M15 · locked controlled evaluation.** Fit the final acceptance policies on calibration data, freeze all systems, then have D evaluate all 500 locked cases once, including the 150 reserved transfer inputs. Report both co-primary results for both systems. For the symbolic release require the native resource budget, at least 300/500 singleton acceptances overall and at least 300/400 on single-reading inputs, and a one-sided 95% lower confidence bound of at least 95% on adjudicated accepted accuracy. Publish correct-set yield on the 100 ambiguous cases alongside those thresholds. To claim transfer within the registered neural margin, independently require the paired upper limit on the 150 locked transfer cases to be below +10 points. Report a failed or inconclusive transfer comparison alongside any aggregate release result.

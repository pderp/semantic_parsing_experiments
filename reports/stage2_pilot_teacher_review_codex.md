# Independent review of the first teacher pilot batch

D reports exact agreement on **100/100 training inputs**, including both readings on all 20 ambiguous inputs. That is a successful batch-level check of the submitted labels against the seed contract. The targets for this batch were public. The result supports trying the same labeling method on the private-target confirmation batch. It does not establish how an independent bulk run would perform. [Pilot report](stage2_pilot_teacher.md)

**What I verified.** The public target file has 100 distinct IDs and texts. Every ID/text pair matches the released training file. It contains 80 singleton sets and 20 two-reading sets, with 120 distinct target strings. All 120 parse as closed terms and normalize back to their original canonical strings. The file digest is `0a7436f16c3947d669887212a784f7672c9862128cfd0f59ce875b80f7b75198`. The submitter's final digest and D's score are documented by D. I checked the target side independently. I did not access the teacher's workspace, its submitted bytes, or D's private targets. [Public targets](../data/controlled/pilot_targets_v1.jsonl) · [Release digests](corpus_v1.md)

**Interpretation.** Having the teacher commit a digest before scoring limits post-score correction. Repairing one parenthesis before commitment is part of the stated interactive method. The 100 inputs shared one model session, the full contract, material already available in the project and a common generation grammar. Exact agreement counts strings and decisions on that batch. It cannot distinguish clean derivation from exposure to the public answers or establish a general per-call success probability. No evidence in the report shows that the teacher consulted the public targets. The private-target confirmation should retain its own numerator and denominator, freeze submissions before feedback, and record any overlap with the first 100. The published reference parser also reconstructs the licensed readings for training inputs, so keeping the teacher isolated from solution code matters even when the target file is private.

**Time and judgments.** The reported timestamps span 327 seconds, or 3.27 elapsed seconds per sentence in a batched interactive session. API latency, token counts, marginal cost and independent repeat consistency remain unmeasured. There were zero teacher–target conflicts to adjudicate. There are still 100 distinct input-level judgments under the audit definition. With no second human ratings or timed first reads, inter-reader disagreement and reader-hours remain unknown. [Pilot audit definition](../docs/plans/05codex_plan.md) · [Registered audit and teacher parameters](../configs/pilot.yaml)

**Stage 2 status.** The tokenizer round trip is a separate gate. It requires pinned model/tokenizer revisions, byte-identical target text and parsed sets after encode/decode, and zero unknown tokens. Parenthesis checks on teacher strings establish none of those properties. The report leaves it open. The operator, actual bulk teacher snapshot and prompt, spending ceiling and sponsor authorization also need a record before bulk annotation. Finite-world agreement has no role in upgrading the exact first-batch result. [Neural serialization gate](../docs/plans/05codex_plan.md) · [Stage 2 criteria](../configs/pilot.yaml)
